# Ariel Borst — Portfolio

Responsive dark portfolio built with React, TypeScript, and Vite.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Import this folder into Vercel as a Vite project. Build command: `npm run build`; output directory: `dist`.

## Edit content

- `src/data/projects.ts` — featured project details, statuses, and optional URLs.
- `src/main.tsx` — homepage content and interactive UI.
- `src/styles/main.css` — design system and responsive styling.

## Before publishing

- Replace the illustrative project mockups with screenshots of actual work.
- Confirm a direct email address and add a working contact link.
- Add the final résumé PDF to `public/` and link it from navigation.
- Replace the generic GitHub link with the actual profile URL, or remove it.
- Add case study pages with evidence of outcomes, not invented metrics.
- Verify accessibility, links, and mobile rendering on the deployed site.
